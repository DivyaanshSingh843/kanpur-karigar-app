# Kanpur Karigar — Hyperlocal Food Artisan & Halwai Hiring Platform

An interactive mobile application prototype designed for Kanpur's food & catering trade (Halwais, Tandoor Masters, Bawarchis, Chaat Specialists) based on the official wireframe specifications.

## 📱 Live Web Prototype (GitHub Pages)
Once GitHub Pages is activated, this app runs live on any desktop or smartphone browser with interactive phone framing.

## 🚀 Key Features
- **15 Interactive Screens**: Splash, Language Selection, Login & OTP, Role Switcher, Employer Registration, Employer Dashboard, Post Requirement, Search Karigars, Karigar Detail Profile, Karigar Registration, Karigar Job Feed, Notifications & Activity, WhatsApp Broadcast, My Profile & Settings, and Admin Dispatch Portal.
- **Bilingual Interface**: Hindi (Devanagari) alongside English terminology.
- **Device Frame Mockup**: Styled with realistic iPhone casing, speaker notch, dynamic status bar, and bottom tab bar navigation.
- **Local Kanpur Focus**: Pre-configured with major catering hubs (Kidwai Nagar, Gumti No. 5, Swaroop Nagar, Govind Nagar, Civil Lines).

## 🛠️ Tech Stack
- Single-Page Application (HTML5 / Modern CSS3 / Vanilla JavaScript)
- Font Awesome 6.5
- Google Fonts (Plus Jakarta Sans & Tiro Devanagari Hindi)
